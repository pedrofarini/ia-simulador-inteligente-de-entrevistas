# Resumo Analítico da Vaga: Desenvolvedor Full Stack Júnior

## 🎯 Propósito do Cargo
O cargo de **Desenvolvedor Full Stack Júnior** tem como objetivo apoiar no desenvolvimento de aplicações web completas, atuando tanto no **frontend** quanto no **backend**, com foco em aprendizado e evolução contínua dentro da equipe.

## 📊 Senioridade
- **Nível:** Júnior  
- **Justificativa:** Vaga destinada a profissionais em início de carreira, com potencial de crescimento e desenvolvimento técnico, recebendo suporte e mentoria de colegas mais experientes.

## 🛠️ Stack Tecnológico
- **Backend:** Node.js  
- **Frontend:** React  
- **Práticas esperadas:**  
  - Desenvolvimento de aplicações escaláveis  
  - Boas práticas de versionamento e colaboração em equipe  
  - Acompanhamento de padrões de qualidade e testes básicos

## 🤝 Soft Skills Valorizadas
- Comunicação assertiva  
- Aprendizado contínuo (learnability)  
- Atenção aos detalhes  
- Resolução de problemas (troubleshooting)  
- Trabalho em equipe  
- Adaptabilidade  
- Inteligência emocional  
- Pensamento crítico  
- Gestão de tempo  
- Proatividade  
- Receptividade a feedback
